# ft_root — Documentation Reverse Engineering

Site de documentation du club cybersécurité **ft_root** de l'école 42Lyon.

## Contenu

- **Outils** — liste des outils disponibles dans l'environnement ft_root avec leurs commandes de base
- **Workflows** — méthodologies par type de binaire (ELF, .NET, APK, WASM, Go, Lua...)

## Site

[ft-root-42lyon.github.io](https://ft-root-42lyon.github.io/workflows.html)

## Environnement

L'environnement de reverse engineering ft_root est un JuNest préconfiguré avec tous les outils nécessaires, disponible sur les machines de l'école 42Lyon.

```bash
# Lancer l'environnement
/sgoinfre/ft-root/start.sh

# Mettre à jour l'environnement
/sgoinfre/ft-root/start.sh --update
```

## Club

**ft_root** est le club cybersécurité de l'école 42Lyon.
Son objectif est de former et d'initier les étudiants à la cybersécurité.
